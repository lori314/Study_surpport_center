# 学业支持中心门户网站

这是我在《走近软件》课程里和团队一起做的一个短期网页项目。当时时间比较紧，大家都是刚开始接触前端，所以目标很直接：先把一个“学业支持中心”的门户网站做出来，让首页、活动、课程资料、答疑等页面能连成一套浏览流程。

项目后来没有继续维护，但我自己当时负责的页面确实花了不少心思，所以这个仓库更适合当作一段早期团队开发记录保留下来。

**在线页面：** https://lori314.github.io/Study_surpport_center/

## 我负责的部分

我主要做的是课程资料相关页面，以及答疑墙的前端交互。

### 课程资料

入口在 [dian.html](dian.html)。

当时按照三门基础课程把内容拆成：

```text
工科数分
├── 题库
├── 课件及教参
└── 学长笔记

程序设计
├── 题解
├── 课件及教参
└── 学长笔记

高等代数
├── 题库
├── 课件及教参
└── 学长笔记
```

对应页面里做了课程切换、资料分类、列表展示以及下载 / 上传入口。

这个仓库最开始把很多课程 PDF、PPT、往年题和 ZIP 也一起提交了。现在主分支只保留网页和分类结构，课程资料文件本身不再随仓库分发；原始提交版本完整保留在：

```text
archive-original-course-site
```

### 答疑墙

答疑墙的展示页现在放在：

[answer_wall/question.html](answer_wall/question.html)

当时做的是纯前端交互原型。页面里预置了几条问题，可以：

- 点击“关注”切换状态；
- 点击“解答”展开 / 收起输入框；
- 选择本地图片并填写文字；
- 通过 `FileReader` 在当前页面里预览刚提交的回答。

这一版没有接数据库，所以新增的回答只存在当前浏览器页面里，刷新以后不会保留。对我当时来说，重点主要是把问题列表、展开交互、图片预览和样式完整做出来。

## 整个网站

团队最后做出来的页面还包括：

- 首页和新闻公告；
- “源”桌会等活动页面；
- 往期活动回顾；
- 国际交流相关页面；
- 登录 / 注册 / 个人中心页面原型；
- 课程资料和答疑页面。

整个站点主要使用：

```text
HTML
CSS
JavaScript
jQuery
```

是一个静态课程网站，没有持续运行的后端和数据库。

## 目录

```text
assets/images/     页面图片和活动素材
assets/css/        页面样式
assets/js/         第三方前端脚本
answer_wall/       答疑墙前端原型
*.html             各功能页面
```

原来散在根目录里的图片、样式和前端脚本现在分别放到了 `assets/images/`、`assets/css/` 和 `assets/js/`，根目录只保留页面文件和 README。

## 本地查看

直接打开：

```text
index.html
```

即可浏览大部分页面。

如果使用 VS Code，也可以用 Live Server 之类的静态服务器打开。

## 关于这个项目

现在回头看，文件命名、CSS 复用和页面组织都比较初期，不同成员写出来的风格也不完全一致。但它确实是我比较早的一次多人网页协作：第一次需要把自己的页面接进别人的导航和整体视觉里，也第一次开始考虑一个页面之外，多个页面之间怎么跳转、怎么保持统一的使用体验。

主题和其它页面内容是团队课程作品，这个仓库保留的是当时的项目实现记录。
